# SunuGestion 🏢🇸🇳

**SunuGestion** est la plateforme SaaS moderne de référence pour la gestion immobilière au Sénégal (Dakar, Thiès, Saly, Almadies, etc.). Elle simplifie la gestion locative, le suivi des paiements, la gestion des propriétaires, des unités et des contrats.

---

## 🚀 Fonctionnalités Clés

- **Tableau de Bord Intuitif :** Statistiques financières en temps réel (revenus mensuels, taux d'occupation, loyers perçus et impayés en FCFA).
- **Gestion des Biens Immobiliers :** Immeubles, résidences, villas et appartements avec adresses précises au Sénégal.
- **Gestion des Unités & Lots :** Suivi par appartement/studio/commerce avec loyer de base et charges.
- **Gestion des Locataires :** Fiches complètes avec coordonnées sénégalaises (+221), CNI/Passeport et historique.
- **Contrats de Bail :** Suivi des dates d'entrée, durées, montants de caution et états des lieux.
- **Paiements & Recouvrement :** Enregistrement des quittances, reçus et historique des paiements (Wave, Orange Money, virement bancaire).
- **Gestion des Dépenses :** Suivi des charges déductibles et des travaux.
- **Mobile First & 100% Responsive :** Navigation optimisée pour smartphone avec tiroir latéral escamotable et menu hamburger tactile.
- **Synchronisation Fullstack Supabase :** Données persistantes et sécurisées avec API temps réel.

---

## 🛠️ Stack Technologique

- **Framework :** [Next.js 14](https://nextjs.org/) (App Router, React 18, TypeScript)
- **Styling :** Tailwind CSS & Lucide Icons
- **Base de Données & Auth :** [Supabase](https://supabase.com/) (PostgreSQL)
- **Déploiement :** Vercel

---

## 📱 Expérience Mobile

L'application a été entièrement adaptée pour une utilisation fluide sur mobile :
- Menu hamburger escamotable avec tiroir latéral off-canvas.
- Fond flouté pour focalisation contextuelle.
- Tableaux avec défilement tactile fluide.
- Formulaires ergonomiques adaptés aux claviers tactiles.

## 💻 Installation & Démarrage

```bash
# Cloner le dépôt
git clone https://github.com/Mahamar1/sunugestion.git

# Installer les dépendances
npm install

# Lancer le serveur de développement
npm run dev
```

L'application sera accessible sur `http://localhost:3000`.
